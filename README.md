# Showrunner 放映员

> 手机编排频道，电视按权限播放——把电视台与可控点播体验带回家。

文档按 **WHY → WHAT → HOW → ADR** 组织，入口见 [文档导航](docs/README.md)。

## 这是什么

Showrunner 是一个家庭点播系统，核心设计是**服务器权威队列**：

- **手机（家长）**：唯一的编排入口。浏览电脑里的媒体库、添加/排序/删除节目、控制播放。
- **电视（孩子）**：一台"哑终端"。全屏播放，没有片单、没有推荐、不响应任何键鼠操作，播完自动下一部，全部播完进入待机画面。

电视端没有任何可选择的东西，因此不存在"防破解"问题——就像小时候的电视机，放什么，看什么。

## 快速开始

### 环境要求

- Node.js ≥ 18（开发于 Node 24）
- 一台接着电视的电脑（Windows / macOS / Linux 均可）

### 安装与启动

```bash
npm install
npm start
```

> **两种分发方式**：开发者 `git clone`（纯代码，无二进制）→ `scripts\install.bat` 自动补齐环境；用户直接用打包好的 `showrunner-portable-*.zip`（含便携 Node + 全部工具），解压双击 `start.bat` 即用。打新包：`scripts\package.bat`（含自启动验证）。详见 [docs/DEPLOY.md](docs/DEPLOY.md)。

首次启动会自动生成遥控器密码并打印在控制台；`config.json` 只保存 scrypt 哈希，不保存明文：

```
  Showrunner 放映员已启动
  电视播放端:  http://localhost:7100/tv/
  手机遥控器:  http://本机IP:7100/remote/
  首次运行，已生成遥控器密码: xxxxxxxx  （配置文件仅保存密码哈希，请立即记下）
```

### 配置媒体库

不需要改任何配置文件——全部在遥控器网页上完成：

1. 手机打开遥控器 → 「片库」页 → 「＋ 添加目录」
2. 在弹出的目录浏览器里逐层进入影片所在文件夹，点「选择此目录」
3. 片库立即列出该目录（含子目录）里的全部影片

目录会持久化保存，重启不丢；随时可移除（不删磁盘文件）。也可以用 `config.json` 的 `mediaDirs` 或 `--media` 参数预置目录，两者会合并。

### 添加网页片源

频道编辑里点「＋ 添加节目」→「贴链接」，粘贴 B 站 / 优酷 / YouTube 链接——服务端自动抓标题入列，并**在后台用 yt-dlp 提前下载到本地缓存**（`cache/<站点>/<标题>-<内容ID>.mp4`）。轮到播放时电视直接播缓存文件：零广告、零卡顿、零网页逻辑。遥控器上每个网页条目都有缓存徽标（⏳ 缓存中 xx% / ✅ 已缓存 / ⚠️ 失败可重试）；播出队列变化时会自动预取当前 + 后续 2 个网页条目。

缓存相关配置（`config.json`）：

| 键 | 说明 |
|---|---|
| `ytdlpPath` | yt-dlp 路径（默认自动查找 PATH，内置 `bin/yt-dlp.exe` 兜底） |
| `cookiesFromBrowser` | 下载需要登录的站点时借用浏览器登录态，如 `"chrome"`、`"edge"` |
| `cacheMaxGB` | 缓存容量上限（默认 20 GB），超出后自动淘汰最久未播的 |

未安装 yt-dlp 时网页条目会在电视端提示"缓存失败"并自动跳过，不影响本地片播放。项目已内置 ffmpeg：B 站等音视频分离的站点会自动合并成完整 mp4（没有 ffmpeg 时自动退回单文件格式，此类站点会失败）。

### 日常使用

1. **电视端**：无需手动操作——服务端启动后自动拉起 kiosk Chrome（全屏锁定，输出到电视），崩溃或被关闭会自动重拉。
2. **手机端**：手机与电脑同一局域网，浏览器打开 `http://电脑IP:7100/remote/`，输入密码。建议"添加到主屏幕"，体验等同 App。
3. **频道**：「频道」页 →「＋」新建频道 → 添加、排序节目并启用。可同时启用多个频道；电视端用电脑遥控器操作：`↑/↓` 选择、`←` 确认、`→` 打开菜单/返回。鼠标仍可使用，但不是必需。
4. 频道可开启电视端点播权限，也可关闭自动播出成为纯点播频道。每个节目可设置每日开播时间和播放上限；播放上限适合裁掉网页视频片尾垫料，到时强切。

片库按「媒体根目录 → 子目录 → 文件」树形展示。在“从片库加入”时可勾选单个文件或整个目录；勾选目录会一次加入其中全部视频，频道和合集编辑均支持。

### 电视台式编排

- **循环播放**：频道编辑里勾选「循环」，播到队尾自动回卷重播（时刻表规则也可以单独带循环）。
- **合集（连续剧模式）**：「合集」页建一个合集（如《地球脉动》），装入若干集。频道里添加「合集抽一集」条目——每次轮到它播出，自动抽合集中的下一集，标题显示为「《地球脉动》第 3 集 …」。顺序播（播完自动从头再来）或随机抽（一轮内不重复）两种模式；游标持久化，重启不串集。
- **网站合集导入**：「合集」页点「导入网站合集」，可粘贴 B 站合集里的任意一集、B 站分 P 视频或其他 yt-dlp 支持的播放列表链接，系统会自动反查并按网站顺序批量创建剧集；普通单视频链接也可导入为一集。
- **播出时刻表**：「时刻表」页设定「周几 + 时段 → 播哪个频道（可循环）」。频道内还可为节目设置每日 `HH:MM` 开播点；提前播完显示待机画面，下一档到点强制切换。
- **资产备份与分享**：「频道」页点「备份资产」下载无损 `.showrunner.json`，可合并导入或完整恢复；适合放入 `shared-assets/` 提交分享。系统还会在本地保留滚动历史，并在 Windows 的 `%LOCALAPPDATA%/Showrunner/assets/` 留一份独立于安装目录的镜像。
- **阅读版节目表**：「频道」页点「导出阅读版」，下载 Markdown 节目表（时刻表 + 各频道内容 + 合集进度），可打印贴在电视旁；它不是恢复备份。
- **预取**：播出队列变化时自动缓存「当前 + 后续 2 个」网页条目——播 A 时 B、C 已经在下载。

### 维护模式

需要临时操作电视那台电脑时（装软件、扫码续期、调系统设置），在遥控器「正在播放」页点「进入维护模式」：

- kiosk 锁定画面被关闭，Showrunner 打开一个受控的非 kiosk 普通窗口
- **约 10 分钟无操作自动回锁**，kiosk 重新拉起；也可随时点「立即回锁」
- 退出维护时会先关闭这个受控普通窗口，再拉起 kiosk；两者不会同时存在
- 受控窗口使用独立浏览器配置，关闭它不会误伤你自己开着的 Chrome/Edge 窗口

相关配置（`config.json`）：`"manageBrowser": false` 关闭浏览器托管；`"chromePath": "..."` 指定浏览器路径。

如果要把电脑长期释放出来做别的事，点「下线」：受控 kiosk 会关闭且看门狗不会重拉，下线状态会跨重启保存；手机后台仍可登录并点「重新上线」。这与 10 分钟自动回锁的临时维护模式不同。

遥控器还可直接修改为指定密码（8–128 个字符）；保存后其他设备的旧会话立即失效。Windows 上可在同一页开启或关闭登录时自启动，无需手动运行脚本。

## 命令行参数

`npm start -- --port 8080 --host 0.0.0.0 --media D:\影片 --password xxx`

| 参数 | 说明 |
|---|---|
| `--port` / `--host` | 监听地址（默认 7100 / 0.0.0.0） |
| `--media <dir>` | 追加一个媒体目录（可多次） |
| `--data <file>` | 数据文件位置 |
| `--password` | 遥控器密码（也可用环境变量 `SHOWRUNNER_PASSWORD`） |

优先级：命令行 > 环境变量 > config.json > 默认值。

## 公网访问（可选）

你有公网 IP + DDNS 时，可用 Caddy 反向代理让手机在外编排。路由器只把公网 **443** 转发到 Caddy，绝不能把 7100 直接映射到公网。使用强密码，并让 Caddy 自动签发 HTTPS 证书。

**安全红线**：公网只允许 `/remote`、`/api` 和已鉴权的 `/ws-remote`。`/tv`、`/media`、`/cache`、`/ws-tv` 以及兼容旧版的 `/ws` 都是局域网接口，必须屏蔽。采用白名单比逐项黑名单更不容易漏掉新接口：

```caddyfile
tv.example.com {
    @public path /remote /remote/* /api /api/* /ws-remote
    handle @public {
        reverse_proxy 127.0.0.1:7100
    }
    handle {
        respond 404
    }
}
```

应用已启用登录限速、`HttpOnly`/`SameSite=Strict` Cookie（HTTPS 下自动 `Secure`）、密码哈希、WebSocket 遥控鉴权及浏览器安全响应头。它仍不是面向不受信任多租户的服务；建议再在 Caddy、VPN 或防火墙层限制来源，并及时更新系统与依赖。

## 项目结构

```
showrunner/
├── src/
│   ├── server.js      # 入口：装配 + 启动
│   ├── config.js      # 配置加载（文件/环境变量/命令行）
│   ├── queue.js       # 队列状态机 —— 播出行为的唯一权威
│   ├── playlists.js   # 频道管理（保留历史文件名兼容数据/API）
│   ├── collections.js # 合集：连续剧式内容包 + 集数游标
│   ├── scheduler.js   # 播出时刻表：时段→频道，transition-only 跃迁
│   ├── library.js     # 媒体库扫描，稳定 ID
│   ├── browse.js      # 文件系统浏览（网页选目录）
│   ├── webtitle.js    # 网页片源标题解析（剥 SEO 后缀）
│   ├── ytdlp.js       # yt-dlp 封装：查信息 / 下载 / 进度解析
│   ├── sources/       # 网站源注册表：公共兜底 + 各站独立适配器
│   ├── cache.js       # 网页片源缓存：规范命名 / 索引 / LRU / 预取
│   ├── store.js       # JSON 原子持久化
│   ├── auth.js        # 密码登录 / 会话
│   ├── ws.js          # WebSocket：状态推送 + 电视上报
│   └── routes/
│       ├── api.js     # 遥控器 REST API
│       └── media.js   # 视频流（Range）：本地媒体 + 网页缓存
├── public/
│   ├── remote/        # 手机遥控器（PWA 友好的移动页）
│   └── tv/            # 电视播放端（只读、锁输入）
├── bin/
│   ├── yt-dlp.exe     # 内置 yt-dlp（网页片源下载，不入库，install 自动下载）
│   └── ffmpeg.exe     # 内置 ffmpeg（音视频合并，不入库，install 自动下载）
├── scripts/           # 部署脚本：install / package / autostart / update-tools
├── test/              # 130+ 个测试：单元 + 端到端
└── docs/              # 架构 / API / 测试 / 部署文档
```

## 路线图

- [x] P0 本地媒体：队列 + 流式 + 遥控 + 电视端
- [x] P1 网页片源：yt-dlp 预下载缓存（B 站、YouTube 等），电视端播缓存文件
- [x] P2 电视台式编排：合集抽一集（集数游标）、循环播放、播出时刻表（时段→节目单自动切台）、节目表导出
- [ ] P3 kiosk Chrome 兜底引擎 + 页面净化注入（优酷等 DRM 站点）
- [ ] P4 每日时长上限、观看时段外的硬限制、登录态维护（扫码续期）
