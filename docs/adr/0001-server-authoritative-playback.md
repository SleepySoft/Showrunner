# ADR-0001：服务器权威播出状态

- 状态：接受
- 日期：2026-11-01

## 背景

普通播放器把完整内容目录和选择能力交给电视端，再尝试隐藏按钮或拦截输入。这无法可靠隔离推荐、搜索和站点自身的导航逻辑，也容易让手机与电视产生不一致状态。

## 决策

PC 服务端的 `QueueManager` 是播出状态的唯一权威。手机负责已鉴权的编排和控制；电视只接收当前节目、有限的即将播出信息与获准展示的频道信息，并上报播放进度、结束和受服务器校验的频道/点播请求。

## 备选方案

- 在电视端保存完整队列：离线操作方便，但形成第二份权威状态并扩大内容暴露面。
- 直接嵌入视频网站播放器：实现快，但推荐、交互、广告和结束事件不可控。

## 后果

- 播出规则、时间强切和合集游标能集中测试和持久化。
- 电视断线时不能自行重新编排，只能保持已有媒体状态并等待重连。
- 电视 WebSocket 虽无需登录，但只能开放在可信局域网，且所有指令必须服务端校验。
