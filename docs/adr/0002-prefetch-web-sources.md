# ADR-0002：网页片源优先预下载缓存

- 状态：接受
- 日期：2026-11-01

## 背景

网页播放受广告、推荐、登录态、网络波动和站点改版影响。家庭电视台需要节目轮到时可预测地播放，也需要裁剪播放上限和稳定的结束事件。

## 决策

使用 yt-dlp 在节目播出前下载当前项及后续两项，必要时由 ffmpeg 合并音视频；电视通过本地 Range 流播放缓存。未就绪显示缓存状态，失败则提示并跳过。

## 备选方案

- 电视直接打开网页：兼容 DRM，但控制能力最弱。
- 实时解析媒体 URL 后串流：减少磁盘使用，但仍受网络波动和链接时效影响。
- 全部内容预先人工下载：最稳定，但失去从遥控器粘贴链接的便利。

## 后果

- 播放稳定、无网页交互，且本地与网页节目使用同一播放路径。
- 需要磁盘配额、LRU 淘汰、下载进度和失败重试。
- DRM 或 yt-dlp 不支持的站点仍需未来的受控浏览器兜底。
