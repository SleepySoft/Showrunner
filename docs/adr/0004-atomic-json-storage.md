# ADR-0004：家庭单机场景使用原子 JSON 持久化

- 状态：接受
- 日期：2026-11-01

## 背景

系统运行在一台家庭电脑上，数据量很小，主要是频道、合集、游标、时刻表和播放位置。部署需要可复制、可备份且不依赖额外服务。

## 决策

配置保存在 `config.json`，运行状态保存在 `data/showrunner.json`，缓存另有索引。状态写入采用临时文件加 rename，避免正常断电或进程中断留下半份 JSON。

## 备选方案

- SQLite：事务和查询更强，但当前没有并发写入和复杂查询需求。
- 外部数据库：利于多机扩展，但显著增加安装、认证和备份成本。
- 浏览器本地存储：部署简单，但无法成为手机和电视之间的服务器权威状态。

## 后果

- 整个目录可迁移，部署和恢复简单。
- 不适合多服务实例并发写入；未来若支持集群或大量历史数据，需要新 ADR 迁移到数据库。
- 数据结构演进必须保留兼容迁移和损坏兜底测试。
