# ADR-0005：公网仅开放遥控平面

- 状态：接受
- 日期：2026-11-01

## 背景

远程编排需要公网访问，但电视页面、媒体流和电视 WebSocket 为局域网体验设计，部分接口不要求登录。直接端口映射 7100 会把媒体和可改变播出状态的电视通道暴露出去。

## 决策

应用继续监听局域网端口；公网部署必须经 HTTPS 反向代理，以白名单仅开放 `/remote`、`/api`、`/ws-remote`。`/tv`、`/media`、`/cache`、`/ws-tv` 和旧兼容 `/ws` 不得公开，路由器只映射反代的 443，不能映射 7100。

遥控 WebSocket 使用 `HttpOnly` 会话 Cookie，登录有限速；Cookie 使用 `SameSite=Strict`，HTTPS 下增加 `Secure`。

## 备选方案

- 给所有电视和媒体接口加相同登录：公网面更统一，但 kiosk 和媒体 Range 鉴权复杂化，仍会公开不必要数据。
- 直接开放 7100：配置最少，但无法维持信任边界。
- 只允许 VPN：安全边界更清晰，但对普通手机用户配置成本更高；仍是推荐的额外保护层。

## 后果

- 反代配置是安全模型的一部分，部署文档必须使用白名单而非易遗漏的黑名单。
- 新增公网端点必须经过安全评审并更新本 ADR或新增 ADR。
- 应用不是多租户互联网服务；公网使用仍应采用强密码、系统更新以及可选的 VPN/来源限制。
