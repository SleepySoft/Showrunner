# ADR-0009：电视端采用最小共同遥控器按键

- 状态：已接受
- 日期：2026-11-01

## WHY

目标电脑遥控器表现为普通鼠标左右键加键盘方向键，不应依赖品牌专用键码、数字键或彩色键。电视端又必须保持受限：用户可以切换获准频道和点播获准节目，但不能在电视上改编排、权限或片库。

## WHAT

以鼠标左右键加四个方向键作为最小产品协议：

- 方向键：在当前菜单移动选择；纵向菜单中上/左为前一项，下/右为后一项。
- 鼠标左键：点击确认。
- 鼠标右键：打开菜单；在菜单中返回上一层或关闭。

键盘 `Enter`/遥控器 `OK` 作为确认别名，`Escape`/`ContextMenu`/`BrowserBack` 作为鼠标右键的菜单返回别名。音量、多媒体和电源键不进入网页协议：音量继续由 Windows 处理；网页不实施关机、睡眠或开机，也不宣称能屏蔽系统级电源事件。

菜单只有两层：启用频道列表，以及当前频道在 `allowOnDemand=true` 时披露的节目列表。所有选择仍通过 `/ws-tv` 发送请求并由服务端复核权限。

## HOW

- 播放时菜单默认隐藏；鼠标右键打开频道列表。
- 方向键选择，鼠标左键或 Enter 确认频道或节目；选择后菜单关闭并自动开始相应播放。
- 在节目层按鼠标右键回频道层，在频道层按鼠标右键关闭；左键点菜单外也关闭。
- 鼠标移动只移动指针和焦点，不再自动打开菜单，避免菜单关闭后立即被重新唤回。
- 菜单焦点用高对比描边表示，并在状态刷新后按频道 ID 保持，不依赖 DOM 原生焦点。
- 只有已识别的导航键调用 `preventDefault()`；其余键原样交给浏览器和操作系统。
- 鼠标悬停与方向键共享同一高亮焦点，二者可随时混用。

## 后果

- 能发送鼠标左右键与普通方向键的电脑遥控器即可完整操作核心电视功能，普通鼠标和键盘也可直接调试。
- Enter/OK 是确认别名，Escape/返回键是菜单键别名，避免必须使用鼠标左键完成确认。
- 电源键若被遥控器驱动映射为系统睡眠/关机，需要在 Windows 电源策略或遥控器驱动中处理，网页层无法可靠拦截。
