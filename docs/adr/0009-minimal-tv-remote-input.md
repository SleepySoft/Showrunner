# ADR-0009：电视端采用最小共同遥控器按键

- 状态：已接受
- 日期：2026-11-01

## WHY

电脑遥控器通常只表现为键盘，不同品牌的专用键码差异很大。若交互依赖鼠标、数字键、彩色键或完整方向键，会把硬件兼容性变成持续维护负担。电视端又必须保持受限：用户可以切换获准频道和点播获准节目，但不能在电视上改编排、权限或片库。

## WHAT

以四个导航键作为产品协议：

- 上 / 下：在当前菜单移动选择。
- 左：确认。
- 右：打开菜单；在菜单中返回上一层或关闭。

键盘 `Enter`/遥控器 `OK` 作为确认别名，`Escape`/`ContextMenu`/`BrowserBack` 作为菜单返回别名。音量、多媒体和电源键不进入网页协议：音量继续由 Windows 处理；网页不实施关机、睡眠或开机，也不宣称能屏蔽系统级电源事件。

菜单只有两层：启用频道列表，以及当前频道在 `allowOnDemand=true` 时披露的节目列表。所有选择仍通过 `/ws-tv` 发送请求并由服务端复核权限。

## HOW

- 播放时菜单默认隐藏；按右键打开频道列表。
- 上下选择，左键确认频道或节目；选择后菜单关闭并自动开始相应播放。
- 在节目层按右键回频道层，在频道层按右键关闭。
- 菜单焦点用高对比描边表示，并在状态刷新后按频道 ID 保持，不依赖 DOM 原生焦点。
- 只有已识别的导航键调用 `preventDefault()`；其余键原样交给浏览器和操作系统。
- 鼠标仍作为调试和过渡输入保留，但不再是完成频道切换与点播的必要条件。

## 后果

- 仅能发送普通键盘方向键的廉价遥控器即可完整操作核心电视功能。
- 左/右的语义是本产品约定，与部分机顶盒“左返回、OK 确认”的习惯不同；界面常驻显示按键提示。
- 电源键若被遥控器驱动映射为系统睡眠/关机，需要在 Windows 电源策略或遥控器驱动中处理，网页层无法可靠拦截。
