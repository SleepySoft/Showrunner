# ADR-0013：忘记密码时通过本机电视确认重置

- 状态：已接受
- 日期：2026-11-01

## WHY

修改密码要求输入当前密码，但家庭电视电脑通常以 kiosk 或静默自启动运行，用户忘记密码后既无法进入遥控器，也不一定能看到控制台。直接提供无验证的重置接口会让同一网络或公网反向代理访问者接管控制平面。

## WHAT

遥控器登录页提供“忘记密码”。请求只能从局域网 IP 直接访问，反向代理头或公网域名会被拒绝。请求成功后，六位一次性重置码只显示在本机电视画面；用户在手机上输入该码和新密码后完成恢复。

重置码十分钟有效、同一请求重复使用原码、连续五次错误后锁定十五分钟。成功后保存新的 scrypt 哈希并撤销所有旧会话。

## HOW

`PasswordRecovery` 只在内存保存确认码、有效期和失败计数，重启即失效。`/tv/setup-info` 仍只允许 loopback 读取，因此局域网手机和公网客户端都拿不到确认码。公开状态接口只披露是否存在恢复请求和过期时间。

请求和确认接口同时检查 socket 地址及 HTTP Host 必须为 loopback/RFC1918/本地 IPv6，且拒绝 `Forwarded`、`X-Forwarded-For`，从而把物理电视可见性作为恢复凭证。密码写盘成功后才替换运行时鉴权状态。

## 后果

- 用户不需要当前密码、控制台或远程终端即可恢复。
- 能看到电视且能直连局域网遥控器的人可以重置密码，符合家庭设备的物理信任边界。
- 公网域名不能使用该功能；必须回到家庭局域网并按电视显示的 IP 访问。
- 局域网攻击者可以发起一次电视提示，但拿不到确认码；有效期和频率限制控制骚扰与猜码风险。
