# 架构决策记录（ADR）

## 状态

- `提议`：仍在讨论，不能作为实现依据。
- `接受`：当前实现遵循该决定。
- `废弃`：决定已被替换，但保留历史。
- `取代`：本文取代另一份 ADR，并链接旧记录。

## 编号与修改规则

- 文件名使用四位递增编号：`NNNN-short-title.md`。
- 已接受 ADR 不重写历史结论；方向变化时新增 ADR，并把旧记录标记为废弃或被取代。
- 文字澄清、链接修复和与实现同步的事实修订可以直接修改。

当前最新决策：[ADR-0009：电视端采用最小共同遥控器按键](0009-minimal-tv-remote-input.md)。

## 模板

```md
# ADR-NNNN：标题

- 状态：提议
- 日期：YYYY-MM-DD

## 背景

触发决定的问题、约束和已知事实。

## 决策

选择什么，以及适用边界。

## 备选方案

考虑过但未选择的方案及原因。

## 后果

正面、负面以及后续需要承担的工作。
```
